# Spec — odin-gtksourceview

## Packages

```
gtksourceview/   package gtksourceview: generated by runic from gtksourceview/rune.yml
```

Import through the `gtksourceview` collection: `import "gtksourceview:<package>"`.

## Surface

Every public declaration of the bound headers (GtkSourceView 5 5.12.0), named as runic names
them: `GtkSourceBuffer` is `SourceBuffer`, `gtk_source_buffer_new` is `source_buffer_new`,
`GTK_SOURCE_TYPE_BUFFER` is `SOURCE_TYPE_BUFFER`, plus the hand fixes in [PATCHED.md](PATCHED.md). Deprecated API is bound, because
`GLIB_DISABLE_DEPRECATION_WARNINGS` is set when generating.

## Version

The binding records the library version it was generated from. `make test` compares it
with the version macros of the installed headers.
